# TKD Judge App v1.7.0 – Advance TKDScorer

## Layout update
- Red scoring controls are now on the left; Blue controls are on the right.
- Row 1 contains Red +1 and Blue +1 with an equal column gap.
- Row 2 contains Red +2, Red +3, Blue +3, Blue +2 with the same equal gap between every button.
- Added a clear vertical gap between Row 1 and Row 2.
- Layout is responsive so all scoring buttons fit on the normal landscape screen and scale to the same arrangement in fullscreen.

## Punch icons
- Red +1 uses the supplied red punch icon artwork.
- Blue +1 uses the supplied blue punch icon artwork.

## Scoring behavior
- Red/Blue +2 supports swipe up for +4.
- Red/Blue +3 supports swipe up for +6.
- Existing separate punch, chest, head and swipe audio feedback and vibration settings retained.
