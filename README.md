# Advance TKDScorer Judge App v1.7.1

TKD SCORER ADVANCE judge scoring app.

## v1.7.1 updates
- Brand changed from TKD Score BASIC to TKD SCORER ADVANCE.
- Added TKD SCORER ADVANCE app logo and v1.6.2 version display.
- Added launcher icon.
- Reduced scoring icon size slightly for cleaner button layout.
- Preserved Blue-left / Red-right scoring layout.
- Blue +2 swipe up = +4; Blue +3 swipe up = +6.
- Red +3 swipe up = +6; Red +2 swipe up = +4.
- Preserved reconnect, fullscreen, vibration and sound controls.


## v1.6.2 UI update
- Branding: **TKD**Scorer Advance
- Version shown in the app header
- Scoring icons slightly reduced
- Swipe-up arrow moved higher and kept behind the +2/+3 icon area


## v1.6.2
- TKDScorer Advance: TKD is red and bold.
- Added separate audio feedback for punch, chest protector, head gear, and swipe-up.
- Swipe-capable buttons use the swipe sound only when the upward swipe is completed; normal taps use the point-type sound.

## v1.7.1 layout correction
- Row 1 and Row 2 no longer overlap.
- A fixed visible gap is maintained between the two scoring rows.
- Scoring buttons use responsive flex sizing instead of a fixed minimum height.
- The full scoring grid is designed to fit on the initial landscape screen and remain fitted in fullscreen.

## v1.7.1 QR Connection

The start page now includes **SCAN QR TO CONNECT**. The scanner reads a QR containing the scoring server address and 4-digit court code, fills the connection details, and starts connecting automatically. Manual entry remains available.
