# TKD Judge App v1.7.2

## QR Connect Start Page
- Added a prominent QR scanner connection card to the Judge App start page.
- Added a dedicated QR icon instead of a text glyph.
- Tapping the card opens the camera QR scanner.
- Scanner reads the scoring server address and 4-digit court code and connects automatically.
- Manual server URL and court-code connection remains available below the QR option.
- Updated displayed app version to v1.7.2.
